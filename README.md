# 逐光之野 · Lumenwild

一个可直接游玩的原创 3D 开放世界动作冒险原型，使用 Godot 4、GDScript 与 Compatibility 渲染器制作。借鉴元素组合、队伍切换和自由探索的玩法，角色、故事、地形、建筑、模型、音效与界面均为本项目原创；字体使用 Noto Sans SC。

## 开始游戏

**双击 `开始游戏.cmd`。** 启动器会寻找项目上一级目录中的 Godot 或 PATH 中的 `godot` / `godot4`。当前电脑已经有可用的 Godot 4.7.2。

也可在 Godot 导入本目录的 `project.godot`，按 **F5** 运行。主场景是 `scenes/main.tscn`；世界在运行时生成，因此编辑器视口里的主场景本身是空的。

首次运行选择「踏上旅程」，沿村里的小路接近阿芙，按 **F** 开启主线。随时按 **Esc** 查看操作。

- 第四章「森心苏醒」：找回三枚森心种 → 陪伴萤灵经过风、潮、岩三站 → 净化缚根的守林者 → 把新芽带回村庄，获得 1000 金币谢礼。
- 第五章「晨钟之约」：依次敲响风、潮、星三座钟 → 清除三处灯台守卫并重燃灯火 → 挑战堕曜圣像 → 迎接第一声晨钟，获得 1200 金币谢礼。
- 每轮 18 只宝箱，每只固定 30 金币；开启第 15 只后，保留剩余宝箱并补充已开启的槽位。14 只野外敌人击败第 12 只后同样补充，主线线索守卫和 Boss 不参与刷新。
- 星海祈愿：六批限定卡池，每批三位，初始及每章通关各开放一批；单抽 / 十连、星光动画、共享保底、最近 60 抽记录和角色编队。
- 角色培养：三级经验书、独立角色等级、两次突破、属性成长。23 种角色专属材料与五种元素晶石分布在 84 个采集点，可从培养界面追踪位置。
- 第六章「沉星海书」：第五章后与阿芙交谈，前往西北旧港潜潮门。水下有海底邮局、垂直档案馆、风→海→星声纹钟、信使鳐护送、潮汐锁链与最终抉择；WASD 潜游、空格上浮、Ctrl 下潜、E 声波。沉海宝箱每个 30 金币并掉落冒险心得，开启十个后刷新一轮。
- Blender 4.5 LTS 资产：`assets/blender/lanyin.blend`、`lanyin.glb` 为澜音的长发长裙与月潮法器模型；`sea_chamber.blend`、`sea_chamber.glb` 为水下钟庭模块。安装 Blender 后可继续编辑，Godot 画廊和近景对话会优先显示 Blender 澜音网格。

这是可游玩的单人原型，使用程序化网格与 Blender 网格混合制作偏写实比例的二次元画面。当前美术和肢体动画仍比商业游戏简化，尚未包含配音、装备养成、攀爬或联机。

## 经验书与角色突破

击败怪物会留下可见的经验书，走近两米自动拾取，同时获得「蚀光碎片」。未拾取的掉落会随存档保留，地图上以紫色小方块标记。普通怪固定掉落「旅途札记」×2，额外有 25% 概率掉落「冒险心得」×1、5% 概率掉落「星辉典藏」×1；Boss 固定掉落心得 ×4、典藏 ×1，普通怪/Boss 的碎片数量分别为 1/4。

三种书分别提供 **100 / 500 / 2000 经验**。按 **U** 或从 C 图鉴进入培养页，选择已获得的角色，可使用一本或最多十本。各角色从 1 级开始，20、40 级需要突破，最高 60 级。达到当前上限即停止批量消耗，多出的一本书内剩余经验会暂存，突破后继续结算；满级后不能继续消耗经验书。升级和突破不消耗金币。

首次突破需要 **专属材料 ×3、同元素辉晶 ×2、蚀光碎片 ×4**，第二次需要 **×6、×4、×8**。培养页显示当前持有量和来源，点击「追踪采集」可得到地图与世界路标引导。每种专属材料和辉晶各有三个采集点，按 F 每次获得两份；实际探索十分钟后再生，暂停菜单和关闭游戏不推进再生时间。全部采完时，路标显示再生倒计时。

等级与突破提高攻击伤害和减伤，队伍仍共享生命与爆发能量。未抽到的限定可以查看培养需求和预先采集材料，获得之前无法升级或编队。旧存档保留金币、主线、角色和抽卡保底，新增的等级从 1 级开始；养成数据写入第四版存档，兼容第一至第三版。

## 祈愿与限定角色

- 每抽 **60 金币**，十连 **600 金币**，每个宝箱 **30 金币**。
- 非保底祈愿的角色概率 **1%**，其他结果为旅行药剂 ×1。
- 连续 19 抽没有角色，第 **20 抽必出角色**。任何提前出角色都会重置这 20 抽计数。

- 重复角色每次增加一阶共鸣，每阶伤害 +3%，最多五阶；满阶后重复转为药剂 ×2。

## 存档

自动保存在 Godot 的 `user://lumenwild_save.json`，Windows 通常为：

`%APPDATA%\Godot\app_userdata\逐光之野 · Lumenwild\lumenwild_save.json`

启程、开启宝箱、打败敌人、星核共鸣、主线推进、抽卡、编队与正常退出都会保存。使用临时文件后重命名写入。暂停菜单也可手动保存。重新启程前有覆盖提示。存档记录任务、位置、角色、生命、能量、宝箱、星核、已打败敌人、祈愿计数、角色共鸣、药剂与队伍；未完成的战斗与技能冷却不会跨会话保存。

第四版存档兼容第一、二、三版：保留原有金币、主线、角色和保底，不补发或追回旧宝箱差额。保存宝箱与野怪轮次、生成位置、累计开启数、野怪归属，以及等级、经验书、突破材料、采集再生和未拾取掉落；读档时已清空八成的旧地图会补充。新游戏恢复初始位置，限定全部锁定，养成库存清空。

此前已通关三章的存档可直接继续第四章。萤灵护送保存已完成的路标，读档后从最近路标接续；敲钟进度、灯台守卫、两位新 Boss、角色与卡池轮换同样保存。

刷新位置避开玩家 22 米内、湖面、陡坡、建筑碰撞、主线目标与 Boss 场地。未开启宝箱和仍活着的怪物留在原处；已击败的星核守卫补充为野外普通敌人，不会重新封锁星核。地图随当前位置更新，J 的第一章手记显示轮次和累计开启数。

## 项目结构

- `scripts/main.gd`：任务、存档、战斗调度、交互与特效。
- `scripts/world.gd`：可复现地形、建筑、植物、遗迹与大世界布置。
- `scripts/player.gd` / `enemy.gd`：移动、技能、敌人与 Boss AI。
- `scripts/game_data.gd`：元素、角色、区域与记忆设定。
- `scripts/campaign.gd`：第二、三章主线、线索、机关和 Boss。
