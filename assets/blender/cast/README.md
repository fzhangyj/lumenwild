## 编辑与重新生成

游戏的模型入口是 `scripts/anime_cast.gd`，细节在 `scripts/cast_refinement.gd`；原动画继续使用 `Body / Head / LegL / LegR / ArmL / ArmR / Cape` 分组。

1. 在 Godot 中运行 `tools_export_cast.gd`，导出与游戏同源的 23 份 GLB。
2. 用 Blender 后台运行 `tools_blender_cast.py`，将各个 GLB 转为独立的、可继续编辑的 Blender 工程。
3. `tests/cast_capture.gd` 生成两张全员模型预览。

Blender 工程是可编辑交付副本；在 Blender 内的后续手动修改不会自动回写程序化建模脚本，需要另行导出和接入。项目使用 GLB 交换格式，不依赖 Godot 自动导入 `.blend`。

本轮实测：全员模型和动画分组 29/29，水下剧情 41/41。
